# 캐릭터·말풍선 입력과 이동 검증

캐릭터 창은 현재 캔버스의 불투명 픽셀에서만 클릭과 드래그를 받는다. 말풍선은 둥근 본체와 삼각형 꼬리 안에서만 입력을 받는다. 투명한 여백의 클릭은 뒤쪽 창으로 통과한다. 네이티브 마우스 전달이 중단되어도 `screen` API의 커서 좌표를 창 콘텐츠의 DIP 좌표 및 페이지 확대율로 변환해 입력을 복구한다. 말풍선을 드래그해도 캐릭터와 함께 이동한다.

드래그 중에는 포인터를 캡처하고 화면 가장자리 스냅을 보류한다. 버튼 해제·캡처 취소·포커스 상실 시 드래그를 종료한다. 말풍선은 최신 배치 계산을 적용하며, 이동할 때마다 설정된 크기와 위치를 함께 지정한다. `setPosition()`의 네이티브 크기 읽기·쓰기 과정에서 소수 배율 반올림이 누적되는 경로를 사용하지 않는다. 캐릭터 배율은 네이티브 창 크기 대신 Character Size 설정을 따른다.

## 검증 항목

- `pnpm lint`, `pnpm test:coverage --runInBand`를 실행한다.
- `pnpm test:overlays`는 격리된 Electron 테스트 창에서 2D·3D 및 Character Size 30/40/50/75/100%의 픽셀 판정·30회 왕복 이동을 검증한다. Windows에서는 OS 마우스 입력을 보내 불투명 영역의 앱 클릭, 투명 영역 뒤의 수신 창 클릭, 실제 드래그를 확인한다. 실행 중 테스트 창과 마우스를 조작하지 않는다.
- Overlay Verification CI는 macOS·Windows에서 위 검사를 실행하고 Windows의 `--force-device-scale-factor=1.25`, `1.5`, `2`도 확인한다. 강제 배율 검사는 서로 다른 배율의 물리 모니터 사이 이동을 대체하지 않는다. 결과와 캡처는 `out/overlay-tests/` 및 CI artifact에 저장한다.
- macOS와 Windows에서 2D·3D 모드를 각각 확인한다.
- 캐릭터의 몸체·투명한 모서리·말풍선의 본체·꼬리·둥근 모서리 밖을 클릭한다. 보이는 영역에서만 앱이 반응하고 나머지는 뒤쪽 창이 반응해야 한다.
- 캐릭터와 말풍선을 각각 빠르게 반복 이동한 뒤 같은 위치로 되돌린다. 창 크기와 상대 위치가 누적해서 변하지 않아야 한다.
- 화면 가장자리에서 버튼을 누른 채 잠시 멈춘다. 버튼을 놓기 전에 스냅하지 않아야 한다.
- Character Size 50%·75%·100%와 Windows 디스플레이 배율 100%·125%·150%·200%를 확인한다. 서로 배율이 다른 모니터 사이와 음수 좌표의 모니터로도 이동한다.
- 말풍선 필드·상태를 이동 중에 변경한다. 이전 내용이나 이전 위치로 되돌아가지 않아야 한다.
