# Desktop audit — 2026-10-14

This audit covers the tracked Desktop, hook, collector, rendering, test, build and documentation files. [The inventory](audit-2026-10-14.json) records their reviewed bytes. Source and caller review, regression tests, native interaction checks and generated-file comparisons are separate evidence. A proposed feature document remains a proposal.

## Resulting behavior

- Local and cloud observations enter one application service. Source identity, account identity and observation time remain distinct from display labels.
- App, Web and Touch use one monitoring policy and shared boundary cases. Inactive coding agents are neutral; only actionable notifications and reported errors require attention. The menu tooltip names each badge cause.
- Report age uses server time plus monotonic elapsed time. Visible countdown updates do not extend activity or reopen closed companions.
- Bundled artwork loads locally. Bubble placement uses direct geometry, and 3D pointer checks reuse rendered pixels. No background refresh steals an input draft or recreates a closed dialog.
- Hooks preserve fractional measurements and event order. Claude informational notifications do not change activity. Literal Windows paths work through CMD, PowerShell and Git Bash; inspection and removal understand the same generated commands.
- Local transport preserves base paths, releases unused streams, validates serial descriptors and writes private debounce payloads atomically. Test servers consume request bodies before closing connections.

## Evidence and limits

The [public distribution run](https://github.com/opspresso/vibemon-app/actions/runs/38460613995) verifies Linux/Windows hooks, Python 3.9 installer compatibility, Prometheus queries and 65 public exports. Windows tests use real shells and disposable paths containing spaces, apostrophes, dollar signs, backticks, percent signs and Korean text. They check JSON stdin, event arguments, failing hooks and a missing pinned interpreter.

[Native verification](https://github.com/opspresso/vibemon-app/actions/runs/38459120609) passed on macOS and Windows: workspace, transparent-pixel clicks, dragging, WebGL hit testing and unpacked packaging; Windows additionally tests 125%, 150% and 200% display scales. Later selection regressions also passed against real delayed loopback HTTP: earlier discovery/save replies cannot replace a newer draft. Native captures use synthetic data.

Controlled measurements: stalled-CDN companion startup fell from 5,101 ms to 118 ms; 10,000 isolated bubble placement calculations fell from 370.25625 ms to 0.822125 ms; pointer checks added zero renders instead of 120. These measure those scenarios, not whole-system CPU or end-to-end network latency. History loading moves the edit action by less than 1 px (observed 0 px).

All-dependency audit still identifies two development-only advisories in `braces` and `sprintf-js`, without a compatible patched resolution at review time. The production dependency audit is clean. Incompatible transitive overrides are not used to hide findings.

This is pre-release evidence. PR checks must pass on the final commit. Signed publication, installation and live cloud delivery require separate verification. Release Desktop before publishing the new fractional hook payloads through Web.
